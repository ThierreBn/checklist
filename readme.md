# Checklist

A full-stack checklist application built with JavaScript.

The project is being developed as a full-stack application, with a Node.js backend, PostgreSQL database, and a frontend built with HTML, CSS, and JavaScript.

## Features

- Create tasks
- List tasks
- Update tasks
- Delete tasks
- Set task title
- Set task description
- Set due date
- Set task priority
- Mark tasks as completed
- Persistent task storage with PostgreSQL

## API Endpoints

### `GET /tasks`

Returns all tasks.

**Response:** `200 OK`

### `POST /tasks`

Creates a new task.

#### Required fields

| Field         | Type   | Rules                      |
| ------------- | ------ | -------------------------- |
| `title`       | string | 3–50 characters            |
| `description` | string | 3–255 characters           |
| `dueDate`     | string | Valid date                 |
| `priority`    | string | `low`, `medium`, or `high` |

The `id` and `completed` fields are generated by the database.

**Response:** `201 Created`

### `PATCH /tasks/:id`

Updates one or more fields of an existing task.

#### Editable fields

- `title`
- `description`
- `dueDate`
- `priority`
- `completed`

The `id` field cannot be modified.

**Response:** `200 OK`

### `DELETE /tasks/:id`

Deletes an existing task.

**Response:** `204 No Content`

## Project Structure

The project is divided into two main parts:

- `backend` — Node.js API and application logic
- `frontend` — Checklist user interface

The backend follows a layered structure:

- `controllers` — handles HTTP requests and responses
- `services` — contains application and business logic
- `repositories` — handles database access and persistence
- `utils` — reusable utility functions
- `db.js` — PostgreSQL connection pool configuration

## Database

The backend uses PostgreSQL for persistent task storage.

The database connection is configured through environment variables using a `.env` file.

Example:

```env
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your_password
DB_NAME=checklist
```

The `.env` file should not be committed to the repository.

## Running the Project

### Backend

Open a terminal inside the `backend` folder and install the dependencies:

```bash
npm install
```

Configure the required PostgreSQL environment variables in a `.env` file.

Then start the server:

```bash
node src/index.js
```

The server will run on port `3000`.

### Frontend

Open the frontend using a local development server, such as VS Code Live Server.

The frontend communicates with the backend through the API using the Fetch API.
