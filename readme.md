# Checklist

A simple checklist application built with JavaScript.

The project is currently being developed as a full-stack application, with a Node.js backend and a frontend built with HTML, CSS, and JavaScript.

## Features

- Create tasks
- List tasks
- Update tasks
- Delete tasks
- Set task title
- Set task description
- Set due date
- Set task priority
- Mark tasks as completed

## Technologies

### Backend

- JavaScript
- Node.js
- Native `http` module

### Frontend

- HTML
- CSS
- JavaScript

## API Endpoints

### `GET /tasks`

Returns all tasks.

**Response:** `200 OK`

### `POST /tasks`

Creates a new task.

#### Required fields

| Field         | Type   | Rules                      |
| ------------- | ------ | -------------------------- |
| `title`       | string | 3–50 characters            |
| `description` | string | 3–255 characters           |
| `dueDate`     | string | Valid date                 |
| `priority`    | string | `low`, `medium`, or `high` |

The `id` and `completed` fields are generated by the server.

**Response:** `201 Created`

### `PATCH /tasks/:id`

Updates one or more fields of an existing task.

#### Editable fields

- `title`
- `description`
- `dueDate`
- `priority`
- `completed`

The `id` field cannot be modified.

**Response:** `200 OK`

### `DELETE /tasks/:id`

Deletes an existing task.

**Response:** `204 No Content`

## Project Structure

The project is divided into two main parts:

- `backend` — Node.js API
- `frontend` — Checklist user interface

The backend contains the Node.js API and its business logic.

The frontend contains the user interface of the checklist.

## Running the Project

### Backend

Open a terminal inside the `backend` folder and run:

```bash
node src/index.js
```

The server will run on port `3000`.

## Current Status
